# 测试报告

本次源码快照在 Node.js 24.22.3 上通过 108 项自动回归。另在 Chromium 和新建 SQLite 数据库上验证了首次登录、下载 Excel 模板、CSV 导入、采购决策保存、复核确认、一键下载 A4 PDF 及服务重启后的归档保留。

## 自动回归

在 Node.js 24 或更新版本中执行。

```sh
node --test tests/*.test.mjs
```

| 范围 | 检查内容 |
| --- | --- |
| 评分与排名 | 固定种子复算、三种基准排名、并列名次、评分差异区间和权重边界 |
| 数据导入导出 | Excel、CSV、TSV 的解析，列映射、缺失值定位、导出转义和评估文件往返 |
| 准入与方案 | 阈值核验、人工核验状态、权重方案、排名变化 |
| 服务端项目 | 成员权限、版本冲突、操作记录、复核与历史报告查询 |
| 国际化 | 导入提示、模板工作表名称和报告文本的语言切换 |
