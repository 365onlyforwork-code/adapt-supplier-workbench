# 项目与技术说明

## 项目范围

采购团队在同一评估中维护候选供应商数据、指标标准、准入条件和采购决策。评估员导入数据、核对指标和提交评估。项目管理员分配成员权限，对相应版本给出复核意见。归档后的报告记录确认时的输入、结果及采购决策，后续评估可发布新版本。

| 业务需求 | 系统功能 |
| --- | --- |
| 统一供应商信息 | 支持 Excel、CSV、TSV 导入，校验数据并反馈行列位置 |
| 解释供应商取舍 | 展示综合排名、成对评分差异、指标贡献和权重变化影响 |
| 处理准入要求 | 根据原始指标和人工核验记录符合、待核验和不符合状态 |
| 保留决策依据 | 记录推荐供应商、备选供应商、理由和后续事项 |
| 保留评审记录 | 提交指定版本，负责人确认或退回，下载确认版本 PDF |
| 协作与追溯 | 管理登录、注册审批、项目成员、导出权限和操作记录 |

## 技术结构

| 路径 | 职责 |
| --- | --- |
| `dist/index.html`、`dist/app.mjs` | 网页结构、导航、导入和评估流程 |
| `dist/engine.mjs`、`dist/worker.js` | 评分、排序、权重抽样和后台计算 |
| `dist/import.mjs`、`dist/eligibility.mjs`、`dist/scenarios.mjs` | 文件处理、准入规则和情景对比 |
| `dist/review-document.mjs`、`dist/review-pdf.mjs` | 归档报告和 PDF 输出 |
| `server/accounts.mjs`、`server/api.mjs` | 登录、权限校验、项目版本和操作记录 |
| `scripts/start.mjs`、`drizzle/` | 本地服务入口与数据库迁移 |
| `tests/` | 计算、导入、项目、权限和报告回归测试 |

浏览器在后台线程内执行评分。服务端负责保存项目输入、评估版本、成员角色、复核结果和操作记录。复核确认引用对应的版本，报告内容可按历史版本查询。首次启动创建 SQLite 数据库，运行数据和配置保存在本地环境。

## 评分口径

- 成本型指标按 `min(x) / x` 归一化，效益型指标按 `x / max(x)` 归一化。
- 基准权重以三角重心计算并归一化，支持 WSM、TOPSIS、VIKOR 基准排序。VIKOR 的折中参数为 `0.5`。
- 权重从各指标允许区间均匀抽取后归一化。引擎默认运行 200,000 次抽样，采用 PCG64 和固定种子，保证相同输入可复算。
- 排名稳定性表示候选供应商保持其 WSM 基准名次的抽样频率。成对差异采用同一批权重样本，结合覆盖比例与可接受差异判断结果。
- 比较的理论上下界由权重区间顶点计算。单指标扫描按其他指标的基准比例分配剩余权重，并检查完整权重组合是否可行。
- 准入规则作用于供应商原始数据。应用准入规则后，原始参评集合的综合评分和名次继续保留。
