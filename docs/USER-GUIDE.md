# 使用手册

## 建立评估

1. 在「评估项目」下载 Excel 模板。先阅读「填写说明」，打开「供应商数据」并从第 2 行填写。
2. 每行填写一家供应商，每列填写一个指标，保留第一行的列名。每项指标使用相同的单位。指标值为大于零的有限数值。
3. 点击「新建评估」，填写评估名称，上传文件，核对供应商名称列和参评指标。支持 2–30 家供应商、2–10 项指标，单文件最大 5 MB。
4. 确认各指标的方向和重要程度后点击「开始评估」。采购单价通常为成本型，合格率和准时交付率通常为效益型。可在预览中修改系统识别结果。

需要修正源数据时，按导入反馈定位行和列，修改文件后重新上传。「数据管理」用于查看当前有效数据和已应用的评价标准。

## 对比和决策

- 「评估结果」显示供应商排名、综合评分和排名稳定性。点击「准入条件」设置数值阈值和人工核验项。
- 「供应商对比」可选择任意两家供应商查看评分差异、影响方向和主要贡献指标。
- 「决策偏好」用于调整指标权重及评分差异判断标准。操作后点击「应用设置」或「更新评估」，以已应用的结果为准。
- 「方案对比」可保存多组权重，用同一批供应商数据比较不同优先级下的排名。「采购决策」用于保存推荐、备选、选择依据和后续事项。

## 复核、归档和导出

1. 在「评估结果」打开「复核与归档」，点击「提交复核」。提交前完成采购决策。
2. 项目管理员打开待复核记录，点击「确认并归档」或「退回修改」。确认时锁定对应版本，后续改动另存为新版本。
3. 打开已归档记录，点击「下载 PDF」。也可下载 HTML 或打印同一版报告。下载权限由项目管理员分配。
4. 在「保存与导出」可另外下载当前评估结果 CSV 和完整 `.adapt.json` 评估文件。使用「新建评估」或「导入数据」可导入该项目文件，恢复其数据与评估设置。

## 成员、记录和项目管理

- 新成员通过登录页「注册」填写信息。系统管理员在「账户与工作区」打开「注册审批」处理申请。
- 项目创建者为该项目管理员。在项目内打开「权限与记录」添加获批成员、分配评估员或只读权限，并查看项目操作记录。导出权限可单独分配。
- 项目行尾的操作菜单用于管理项目。未提交或已退回的项目可在「最近删除」恢复。待复核项目先退回。已归档项目可移至「已移出」并恢复到活跃列表，原有报告和记录继续可查阅。
- 页面顶部的语言按钮用于切换简体中文和 English。界面、模板和报告使用所选语言，导入值及用户输入保留原文。
