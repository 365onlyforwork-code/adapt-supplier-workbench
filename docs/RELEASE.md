# 发布维护

本仓库的初始材料以当前源码快照为起点。项目的提交、Issue、标签和 Release 记录以实际发生的工作为准。

| 阶段 | GitHub 操作 | 保留材料 |
| --- | --- | --- |
| 建立仓库 | 创建 Repository | [项目说明、初始需求与技术结构](PROJECT.md) |
| 初始版本 | 首次提交 | 源码快照、[README](../README.md)、使用手册、自动化测试和[版本记录](../CHANGELOG.md) |
| 功能开发 | 按功能提交 | 评分算法、数据导入、可视化等具体改动及验证方式 |
| 方法改进 | 提交并关联 Issue | 评分参数或规则的改动原因、影响范围及验证结果 |
| 系统测试 | 发布测试版本 | [测试报告](TEST-REPORT.md)、版本说明及[演示流程](DEMO.md) |
| 正式发布 | 创建 `v1.0.0` 标签与 Release | 正式源码、启动说明、使用手册与版本记录 |
| 持续维护 | 按实际变更提交 | 企业反馈、功能修正、对应测试及新版本 |

发布说明可引用本次标签的变更记录、运行验证结果和演示材料。归档报告和演示截图使用公开样例数据。
